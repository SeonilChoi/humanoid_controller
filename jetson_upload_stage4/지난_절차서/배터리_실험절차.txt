ARTI-D1 배터리 장착 실험 절차  (2026-11-09 월 오후)
====================================================================================
목적: 배터리를 달아 URDF 무게 (약 5.8 kg) 와 같아진 상태에서
      - 무게가 맞는 기준 데이터 (1.5단계 서기)
      - 오전 (배터리 없음, 약 4.0 kg) 결과와 비교 (3.5 / 4e)
      - 서보가 무거워졌을 때 얼마나 더 느려지는지 측정 (4.5 학습값 확인용)
학습: 3단계 이후 정책은 모두 4.0 ~ 6.4 kg 으로 학습해서 배터리를 달아도 범위 안이에요.

---------------------------------------------------------
[0] 시작 전 확인 (꼭)

   - 배터리 전압: 3셀 (만충 12.6 V, 보통 11~12.6 V) 이어야 해요. 4셀 (14.8 V) 이면 쓰지 마세요.
   - 배터리가 몸체에 단단히 고정됐는지 (흔들리면 무게중심이 움직여요)
   - 장착한 모습 사진 1장 (앞, 옆) -> 결과 폴더에
   - IMU 케이블 / 커넥터가 흔들리지 않게 고정 (오전에 크게 흔들린 뒤 IMU 값이 멈춘 적이 2번 있었어요)

새 터미널을 열 때마다 먼저:
S=~/humanoid_controller/jetson_upload_stage4; C=~/humanoid_controller/config/robot/ARTI-D1

스틱 데드존 0.25 (아직 안 바꿨으면, 스틱이 살짝 밀려서 걸음이 켜지는 것 방지):
cd $C && sed -i 's/stick_deadzone: 0.1/stick_deadzone: 0.25/' robot_stage35.yaml robot_stage4.yaml && grep stick_deadzone robot_stage35.yaml robot_stage4.yaml

공통 규칙
   - 넘어지거나 크게 흔들린 뒤에는 Options 로 다시 시작하지 말고 Ctrl+C 로 끄고 다시 실행
   - 모든 시험은 잡을 준비를 하고, 각 시험 시작 시각을 메모 (로그와 맞출 때 써요)
   - 다리 모터 온도는 끝날 때마다 손으로 확인
