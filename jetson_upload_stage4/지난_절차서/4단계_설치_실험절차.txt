팔 버튼 (정책이 돌 때만 동작, 서 있을 때도 걸을 때도 됨, 넘어지거나 Options 누르면 팔은 0 으로)
   L1        손 흔들기 (오른팔 들고 흔들기) 켜기 / 끄기
   R1        두 팔 들기 / 내리기 반복 켜기 / 끄기
   L2        걸을 때 팔 흔들기 켜기 / 끄기
   R2        팔 동작 전부 끄기 (팔 0 으로)
   방향키 위/아래 (누르고 있기)  두 팔 앞으로 / 뒤로
   오른쪽 스틱 위 (누르고 있기)   두 팔 들기 (많이 밀수록 높이)
      주의: 오른쪽 스틱 좌우는 회전이에요. 위로만 밀어 주세요.

먼저 매단 상태에서 버튼 확인
   - L1 / R1 / L2 / R2 / 방향키를 하나씩 누르고 화면 메시지 (arms wave ON ...) 와 팔 움직임 확인
   - 오른쪽 스틱을 위로 밀었는데 팔이 안 들리고 아래로 밀 때 들리면:
     robot_stage4.yaml 의 raise_sign: -1.0 을 1.0 으로 바꾸기
   - 다른 버튼이 반응하면 (버튼이 밀려 있으면) 어떤 버튼이 무엇을 했는지 메모해 주세요

실험 (바닥에서, 잡을 준비)
   A. 서서 L1 손 흔들기 10초 -> 끄기
   B. 서서 R1 두 팔 들기/내리기 10초 -> 끄기
   C. 서서 오른쪽 스틱 위로 천천히 -> 끝까지 -> 놓기
   D. ✕ 제자리 걸음 + L2 팔 흔들기 20초
   E. 앞으로 걸으면서 L1 손 흔들기
   F. 3.5 와 비교: 서 있기 / 앞으로 / 뒤로 (팔 정책이 더 흔들리는지)
   4e 가 3.5 보다 많이 흔들리거나 떨리면 robot_stage4.yaml 의 model_file 을 agent_stage4b.onnx 로 바꿔서 A~F 다시
